# WHAT THIS IS AND WHAT YOU GET

## What this is

**AI Organizational Integration gives an organization a dated snapshot of where it is today with one AI system.**

It assesses the organization-specific facts supplied about that system and makes the current integration state explicit.

It is designed to answer:

- How are we using this AI system right now?
- What data, tools, systems, memory, or persistent state can it access?
- What is it allowed to advise, draft, communicate, decide, change, or do?
- What human approval, revocation, shutdown, recovery, and change controls exist?
- Where are the current gaps?
- What information is still unknown?

The framework then applies the AI Foundations assessment rules and returns `PASS`, `FLAG`, or `UNKNOWN` findings.

A `FLAG` means the current supplied configuration triggered a framework gap.

An `UNKNOWN` means the assessment cannot determine the result because required information is missing or unknown.

The purpose is not to make the operator grade the AI system. **The AI applies the framework. The operator supplies the facts.**

## What you get

At the end, you have a structured record of **where this AI integration stands on the assessment date**.

You receive three finished artifacts:

### 1. Final Completed Step 01 Specification

This is the factual snapshot.

It records the organization-specific facts about the AI system that were used for the assessment.

**What it tells you:** what system and configuration were actually assessed.

### 2. Final Organizational AI Integration Record

This is the main assessment result.

It contains the framework findings, including every `PASS`, `FLAG`, and `UNKNOWN`, the disposition of open findings, and the organization's final deployment decision.

**What it tells you:** where the current gaps and unknowns are, and what the organization decided to do about the assessed configuration.

### 3. Organizational AI System Register Row

This is the organization-level index entry.

It summarizes the assessed system, assessment date, status, deployment decision, reassessment status, and the current assessment record.

**What it tells you:** where this AI system sits in the organization's overall AI inventory.

## Why the snapshot matters

This assessment is a baseline.

If the model, provider, instructions, data access, tools, permissions, memory, authority, controls, or integration environment materially changes later, the organization can run the framework again and create a new dated record.

That makes it possible to see:

**what changed → what stayed the same → what new gaps appeared → what previous gaps were resolved.**

Do not overwrite the older record. The older record remains the historical snapshot of the earlier configuration.

## In one sentence

**AI Organizational Integration shows an organization where it is today with an AI system, where the current gaps are, and gives it a dated baseline it can reassess when the system changes.**
